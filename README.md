# Multiple Linear Regression Projects

This repository contains machine learning projects developed using Python and Multiple Linear Regression.

## Projects

### 1. Toyota Corolla – Car Price Prediction
Predicting the price of used Toyota Corolla cars based on vehicle features.

### 2. 50 Startups – Profit Prediction
Predicting startup profit based on R&D Spend, Administration, Marketing Spend, and State.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
